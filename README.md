# 寒假工招聘 · 本地原型使用说明

## 打开
解压后双击 `index.html`，不用联网、不用服务器。

## 文件
- `index.html` —— 全部功能都在这一个页面里：列表页 / 详情页 / 报名页 / 防骗提醒页是同页切换，不新开网页、不新建 html
- 导航栏：找工作 / 我要报名 / 防骗提醒（按这个顺序）。“我要报名”在没选具体职位时打开通用报名页，点“去职位列表选一个”再选职位报名；“防骗提醒”点开才显示 6 张卡片，首页不再显示
- 详情页右下角“报名” —— 同页切到该职位的报名页，显示示例电话 + 微信名片二维码（占位），已去掉拨打电话和复制微信号按钮
- `assets/img/wechat-qr.svg` —— 示例二维码占位图，正式用时换成真实微信名片二维码
- `js/jobs.js` —— 全部职位数据，换真实信息只改这里
- `js/main.js` —— 搜索、筛选、排序、详情逻辑
- `css/style.css` —— 样式

## 换成真实招聘信息
打开 `js/jobs.js`，按里面的格式改/加/删职位：
`title（职位名）, type（工厂/物流/服务/教育/线上/其他）, city, pay（数字）, payUnit（元/月 或 元/小时）, days（工期）, dorm（包住/不包住）, meal（包吃/餐补）, desc（工作内容）, need（要求）, contact（联系方式）`

城市和类型如果新增了，顺手在 `index.html` 的两个下拉框里加一个选项。

## 注意
当前 12 个职位是示例数据，联系方式是“待填写”，正式发布前务必换成真实企业和联系方式，并核对薪资、工期、食宿、结算方式。
